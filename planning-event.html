Как считаются долги
Участники — список, выбранный для мероприятия; если он не задан, берутся все пользователи сайта. Для строки со стоимостью: при статусе «Общее» сумма делится между выбранными участниками (по умолчанию — все участники мероприятия), а ответственные считаются теми, кто оплатил; при статусе «Личное» строка не влияет на долги. Для «Общее» можно задать кастомные коэффициенты в процентах для конкретных участников: оставшийся процент автоматически распределяется между остальными, а если кастомные коэффициенты превышают 100%, они нормализуются пропорционально. Если ответственных несколько, оплата делится между ними поровну. Баланс = оплатил − доля. «Кто кому должен» строится так, чтобы закрыть отрицательные и положительные балансы минимальным числом переводов. Округление ведётся до копеек, остатки распределяются по наибольшим дробным остаткам, затем по алфавиту, чтобы результат был честным и повторяемым.
