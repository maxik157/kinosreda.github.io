# Camp equipment

`lada-niva.glb` is the user-supplied “aiprintgen_White Lada Niva 4x4 SUV 3D Model-preview.glb”, processed for the editor. The user supplied this asset for this project; no additional license is asserted here.

Processing: decoded Meshopt, welded/deduplicated, simplified from 172,927 to 57,064 triangles with 0.001 error tolerance, embedded WebP limited to 1024px, removed runtime compression dependencies. Dimensions are 1.68 × 1.64 × 3.72 metres, ground-centred pivot, front along -Z. The runtime uses one solid proxy and a separate roof placement surface. Instances share the cached mesh/texture.

Other equipment is authored in `beer-room-equipment-models.mjs`, with shared materials and batching. Cooler dimensions/handle follow the user photograph. The Doritos front texture is cropped and resampled by row from the user reference, with the bag outline matched to those rows. Small utensils have no movement collisions. The cooler lid and cutting board accept placed drinks/props.
