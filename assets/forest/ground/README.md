# Forest floor detail maps

- `grass-*.webp`: **Grass Ground**, Charlotte Baglioni, Poly Haven.
  https://polyhaven.com/a/grass_ground
- `soil-*.webp`: **Brown Mud Dry**, Poly Haven.
  https://polyhaven.com/a/brown_mud_dry

Both sources are CC0: https://polyhaven.com/license . Color 2048px, OpenGL
normal and roughness 1024px. Original JPEG maps converted to WebP; color maps
use sRGB and data maps stay linear. Detail repeats at 2.5 metres and is blended
by an independent 2048px persistent mask, also sampled by the grass shader.
