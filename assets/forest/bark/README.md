# Tree bark textures

`bark_brown_02-*.webp` derive from **Bark Brown 02**, Poly Haven, CC0.
Source: https://polyhaven.com/a/bark_brown_02
License: https://polyhaven.com/license
Color: 2K; OpenGL normal and roughness: 1K. Converted from original JPEG maps to WebP.

`birch-*.webp` are original procedural grey silver-birch bark maps with charcoal scars and peeling paper, generated by `scripts/generate-birch-bark.py` (Pillow/NumPy). Color: 2K; normal: 1K; roughness: 512px.

Runtime UVs use metres rather than stretching a single bitmap over the full trunk. The renderer shares these maps across all trees and new saplings.

The birch shader blends a desaturated Brown 02 map at the foot of the trunk, with a smooth irregular transition to paper bark above it. Pine maps and UV scale are unchanged.
