# Sky assets

`moon.jpg`: downloaded 2026-11-11 from the Three.js examples texture collection:
https://threejs.org/examples/textures/planets/moon_1024.jpg

Cloud texture, stars and sun are generated locally by `beer-room-sky.mjs`.
The tree atlas in `../forest/` is generated from this project’s own procedural trees with `scripts/bake-forest-crowns.cjs`.
